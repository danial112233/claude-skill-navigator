# Навигатор скиллов для Claude Code

[English](README.md) · **Русский**

Когда установлено несколько десятков плагинов, у Claude Code набираются сотни скиллов, и он часто забывает взять подходящий. Навигатор выбирает за него. Перед каждым запросом быстрая модель Haiku читает твоё сообщение, конец разговора и список установленных скиллов, а потом велит Claude первым делом запустить нужный. Если ничего не подходит, навигатор молчит.

## Как работает

1. Ты отправляешь сообщение.
2. Короткие реплики («ок», «продолжай»), слэш-команды и то, что набрано, пока Claude ещё работает, навигатор пропускает: это поправки по ходу, а не новые задачи.
3. Haiku получает каталог скиллов (он кэшируется), последние четыре реплики разговора и твоё сообщение. Сначала она одной строкой называет дело (`TASK: …`), потом выбирает не больше двух скиллов или отвечает `NONE`.
4. Claude получает указание запустить этот скилл инструментом Skill до ответа. Ты видишь всплывашку `🧭 Беру: /имя-скилла`.
5. Скилл, который Claude уже запускал в этом разговоре, второй раз не навязывается.

Если Haiku не ответила за 8 секунд, сообщение уходит дальше без выбора.

## Точность

Проверено на живой Haiku на 66 настоящих запросах: неверных запусков было 16 в версии 0.2, стало 0 в версии 0.3. В 6 случаях навигатор промолчал, хотя скилл пригодился бы. Это сделано намеренно: промолчать дёшево, Claude всё равно видит все скиллы, а неверный запуск сбивает работу.

## Установка

Нужен Claude Code с поддержкой модов (проверено на 2.1.301).

```bash
claude plugin marketplace add danial112233/claude-skill-navigator
claude plugin install skill-navigator@claude-skill-navigator
```

Потом перезапусти Claude Code или набери `/reload-plugins`. Внутри сессии можно и так:

```
/plugin install skill-navigator --marketplace danial112233/claude-skill-navigator
```

## Команды

| Команда | Что делает |
|---|---|
| `/nav <задача>` | Показывает, что навигатор выбрал бы, ничего не запуская |
| `/nav список` (`/nav list`) | Установленные скиллы по плагинам |
| `/nav выкл` / `/nav вкл` (`off` / `on`) | Выключает и включает навигатор |

## Цена и приватность

- Один запрос к Haiku на сообщение, которое прошло фильтры. Каталог скиллов кэшируется, так что платишь в основном за сообщение и конец разговора.
- Работает через твой аккаунт Claude (подписка или ключ API) и тратит твои лимиты.
- Сообщение и несколько последних реплик уходят только в модель Anthropic через твой аккаунт. Третьим сторонам ничего не передаётся.

## Разработка

```bash
claude plugin validate plugins/skill-navigator
claude plugin test plugins/skill-navigator
```

Встроенные скиллы Claude Code (`plugin-authoring`, `code-review`, `run`…) приходят с пометкой `source: 'builtin'` вместе с командами интерфейса вроде `/clear`, и отличить их нельзя. Поэтому в `hooks/register.ts` есть явный список `BUILTIN_SKILLS`. Если в Claude Code появится новый встроенный скилл, допиши его туда.

Чтобы исправить промах, сначала добавь этот запрос в тесты, потом замерь до и после на живой Haiku. Инструкцию на глаз не правь.
